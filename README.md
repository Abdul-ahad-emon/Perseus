## Assignment Description

This project implements the **Composite Trapezoidal Rule** for numerical integration and improves its accuracy using **Richardson Extrapolation**, forming the **Romberg Integration** method. The performance of Romberg Integration is compared with **Simpson’s Rule** to analyze:

- Accuracy improvement  
- Convergence behavior  
- Error reduction  

The implementation is done in **C++**, and the project includes:

- Construction of the full Romberg table using recursive formulas  
- Numerical comparison with Simpson’s Rule  
- Error decay and convergence analysis using plots  
- A complete LaTeX report with tables, figures, and explanations
